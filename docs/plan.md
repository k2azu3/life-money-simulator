# 企画書:人生まるごとマネーシミュレーター

## コンセプト
「あなたはここに生まれました」から始めて人生を一周しながら、日本の税金・社会保険・年末調整のしくみを体験で覚えるブラウザゲームです。1回のプレイは20〜30分を想定しています。

### 案内役:ゼイ吉(ぜいきち)
- 正体はブタの貯金箱にすみついた「お金の妖精」。少し関西弁でツッコミを入れるお調子者です
- 口ぐせは「ほな、お金の流れ、見ていこか!」
- 計算をまちがえることはありません。そのかわり、ダジャレはよくすべります

## 画面遷移

```
タイトル ─┬─ はじめから → 名前入力 → 物語(シーン)の繰り返し → エンディング
          └─ つづきから(localStorage)

物語シーンの種類
  ├─ story     :ゼイ吉の会話と選択肢(人生の分岐)
  ├─ walls     :年収の壁マップ(アルバイト年収を選ぶ)
  ├─ payslip   :給与明細(額面 → 天引き → 手取り)
  ├─ yearEnd   :年末調整ミニゲーム(書類を集めて申告書に入力)
  ├─ finalReturn:確定申告ルート(年末調整に出さなかった/医療費控除)
  └─ summary   :1年のまとめ(グラフ、サンキー図、「もしも」比較)

どの画面でも使えるもの
  [やさしい解説]:中学生にもわかる言葉と図
  [なぜ?]     :計算の内訳(給与所得控除 → 所得控除 → 課税所得 → 税率 → 税額)
  [記録]      :年ごとの額面と手取りの棒グラフ・折れ線グラフ、獲得バッジ
  [セーブ]    :自動保存+手動保存
```

## 年末調整ミニゲームの仕様

1. **書類集め**:12月、机の上に「書類カード」が6〜8枚出てきます。年末調整に出す書類を選びます。
   - 出すべき書類:扶養控除等申告書、基礎控除申告書、生命保険料控除証明書、地震保険料控除証明書、小規模企業共済等掛金払込証明書(iDeCo)
   - ひっかけ:医療費の領収書、ふるさと納税の受領証明書(年末調整では使えず確定申告が必要)、給与明細、スーパーのレシート
2. **申告書への入力**:選んだ証明書の金額を申告書の欄に入れます。証明書の「年間の支払額」と「12月までの見込額」を読み分けるクイズ付きです。
3. **提出**:エンジンが年税額を計算し、天引き済みの税額との差(還付または追徴)を表示します。
   - 控除漏れがあれば「もしも正しく出していたら +○円」を表示します
   - 「提出しない」を選ぶと、確定申告ルートに進みます(翌年2〜3月にe-Tax風の画面で申告)
4. **確定申告ルート**:医療費控除(10万円を超えた分)や、出し忘れた控除を自分で申告して還付を受けます。
5. **スコア**:正しく出せた控除の割合でランクS〜Cをつけ、バッジ「年末調整マスター」を付与します。

## バッジ(MVP)
はじめての給料、年末調整マスター、控除ハンター(すべての控除を回収)、壁を見きわめた者(家族全体の手取りが一番多い年収を選ぶ)、103万円の壁は昔の話(178万円の壁を知る)、確定申告デビュー、お年玉バンク(お年玉を全部貯金)
