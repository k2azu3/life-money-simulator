# 人生まるごとマネーシミュレーター

生まれてから社会人1年目の年末調整までを体験しながら、日本の税金・社会保険・年末調整のしくみを学ぶブラウザゲーム(MVP=第1部)。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 計算エンジンとゲーム進行の単体テスト
npm run build    # dist/ に静的ファイルを出力(サーバー不要。dist/index.html をホスティング)
```

## 構成

| 場所 | 役割 |
|---|---|
| `src/rules/*.json` | 年度別の税制・社会保険パラメータ(コードに直書きしない) |
| `src/rules/index.ts` | 制度モード(令和8年分固定 / 法定どおり)に応じて設定を返す |
| `src/engine/` | 計算エンジン(所得税・住民税・社会保険・給与明細・年末調整・確定申告・年収の壁)。UIに依存しない純粋関数 |
| `src/game/` | ゲーム状態、セーブ/ロード(localStorage)、バッジ |
| `src/content/` | シナリオ(シーン)と「やさしい解説」の文章 |
| `src/ui/` | React コンポーネント。グラフは依存ライブラリなしの自作SVG |
| `docs/plan.md` | 企画書(画面遷移・ステージ・イベント表・年末調整ゲーム仕様) |
| `docs/tax-parameters.md` | 税制パラメータの調査結果と出典、簡略化の一覧 |

## 制度改正への対応

1. `src/rules/` に新しい年度の JSON を追加する(差分だけでもよい。`2028.json` を参照)
2. `src/rules/index.ts` の `getRules` に年度の対応を追加する
3. `npm test` でテストを更新・確認する
